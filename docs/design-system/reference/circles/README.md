# Circles migration reference

Circles is the first production screen migrated to the Hoyst design system. The approved generated mock establishes the composition and visual hierarchy. Versioned design-system typography, spacing, touch targets and surface tokens govern exact implementation values where the generated image is imprecise.

## Evidence

- `approved-circles-mock.png`: user-approved visual target.
- `ios-circles-dark.png`: direct iPhone 17 Pro Simulator capture at 402 points after implementation.
- `ios-circles-light.png`: direct iPhone 17 Pro Simulator capture at 402 points after implementation.

The screenshots use live local account data, so counts and commitment order may differ from the static mock. Home, Circle Detail, Tap In and the existing tab bar remain outside this migration.
